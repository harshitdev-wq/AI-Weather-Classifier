Model Specifications & Benchmark Verification

Validation Accuracy — 93.29%

The 93.29% validation accuracy is the measured result on the held-out 20% validation split created from the labelled training dataset with a fixed random seed. It is not an accuracy claim for the separate unlabeled external test images.

Confidence vs Ground Truth

The per-image confidence percentage is the softmax probability assigned to the selected class. High confidence can still be wrong, so it should be interpreted as model output rather than ground-truth certainty.
